# 🏨 eHotels – CSI2532

Application web permettant de rechercher, réserver et louer des chambres d’hôtel.

---

## 🚀 Lancer le projet

1. Créer la base de données `ehotels` dans PostgreSQL  
2. Exécuter les fichiers SQL (`schema.sql`, `data.sql`, etc.)  
3. Compiler et lancer le serveur Java  
4. Ouvrir : http://localhost:8000  

---

## 📁 Contenu

- `sql/` : scripts SQL  
- `backend/` : serveur Java  
- `frontend/` : interface utilisateur
